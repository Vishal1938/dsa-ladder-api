A shop runs a “buy two, pay exactly `target`” promotion. Given the prices `nums`, count how many different pairs of items the promotion applies to.

Return the number of index pairs `i < j` with `nums[i] + nums[j] == target`.

**Constraints**
- `1 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
